# SOLID-Python

**Curso na Udemy:** [SOLID na prática com Python](https://www.udemy.com/course/solid-na-pratica-com-python/learn)

**[Certificado de conclusão](https://www.udemy.com/certificate/UC-4e84d450-4c0b-48da-a48b-3774c10e57fc/)**

**Descrição**
Capacitação na aplicação dos 5 princípios SOLID (Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion) utilizando Python. Foco no desenvolvimento de software orientado a objetos (OOP) com maior coesão, baixo acoplamento, escalabilidade e aderência às práticas de Clean Code, visando a manutenibilidade e redução de dívida técnica em projetos.
